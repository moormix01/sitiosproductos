# JACK STREAMING

Sitio web de ventas de cuentas streaming.

## Usar el panel admin
- URL: `/admin`
- Usuario: jack0706
- Contraseña: jack0706

## Variables de entorno (Render)
- `SESSION_SECRET` — clave secreta de sesión
- `ADMIN_USER` — usuario admin (default: jack0706)
- `ADMIN_PASS` — contraseña admin (default: jack0706)
- `PORT` — puerto (Render lo asigna automáticamente)

## Deploy
- Start command: `node index.js`
- Build command: `npm install`
